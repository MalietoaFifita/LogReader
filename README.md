LogReader — CBS Log Analysis Tool for Windows

LogReader is a Python-based command‑line tool designed to help IT support specialists quickly analyze large CBS.log files generated by the Windows operating system. These logs can be thousands of lines long and difficult to navigate manually — LogReader makes them searchable, readable, and easier to troubleshoot.

🚀 Features

Parse CBS log files into structured entries

Separate valid vs malformed lines

Search by system name

Search by keyword (case‑insensitive)

Search by timestamp with flexible partial matching

Supports YYYY-MM-DD

Or full YYYY-MM-DD HH:MM:SS

Display N valid or malformed entries

Count severity levels (INFO, WARNING, ERROR, UNKNOWN)

Robust input validation to prevent crashes

Clean, consistent output formatting via a helper function

🧩 Why I Built This
CBS logs are notoriously large and difficult to read.
As someone working in IT support, I wanted a tool that could:

Load a CBS log

Break it into readable pieces

Let me search for what I need

Help troubleshoot Windows issues faster

The search system — especially the flexible timestamp search — is the part I’m most proud of. It was the most complex feature, and implementing it taught me a lot about parsing, filtering, and designing user-friendly CLI tools.

🛠️ How to Run

Install Python 3

Save the script as LogReader.py

Open a terminal and run:

Code
python LogReader.py

When prompted, enter the full path to your CBS log file:

Example:

Code
C:\Windows\Logs\CBS\CBS.log

📄 Expected Log Format
LogReader expects CBS-style log lines, such as:

Code
2024-06-01 12:30:45, Info CBS Starting TrustedInstaller initialization.

Each valid line contains:

Timestamp

Severity

System

Message

Malformed lines are automatically collected and can be viewed separately.

🔍 Search Options

System Search
Find all entries from a specific subsystem (e.g., CBS, SXS, CSI).

Keyword Search
Search for any word or phrase inside the message field.

Timestamp Search
Supports partial matching:

2024-06-01 → all logs from that date

2024-06-01 12 → logs from that hour

2024-06-01 12:30 → logs from that minute

📊 Severity Statistics
The tool counts:

INFO

WARNING

ERROR

UNKNOWN

Useful for quickly understanding the health of the system.
